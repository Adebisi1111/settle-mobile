# Settle Mobile

Simple USDC payment app built on Arc Network.

## Features
- Send USDC payments
- Wallet integration
- Arc Testnet support
- Circle smart contract integration
- Transaction monitoring

## Tech Stack
- React Native
- Expo
- TypeScript
- Circle SDK
- Arc Network

## Project Structure

```bash
src/
  app/
    index.tsx
    login.tsx
    dashboard.tsx
    send.tsx
```

## Setup

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npx expo start
```
